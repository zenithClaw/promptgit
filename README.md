# PromptGit

**Version control for AI prompts.** Stop guessing whether your edits made things better or worse.

## The Problem

You've been tweaking the same prompt for an hour. You change one word, the output shifts. You change it back, you lose the previous version. You have no idea which version was actually the best.

There's git for code. Why not for prompts?

## What It Does

- **Save prompt versions** — every edit is tracked automatically
- **Side-by-side diff** — see exactly what changed between versions
- **Run & compare** — send two versions to any AI model and compare outputs
- **Share snapshots** — generate a shareable card of your best prompt + output

## Status

🚧 Building in public. MVP coming soon.

## Stack

- Frontend: Vanilla HTML/CSS/JS (fast, no build step)
- Storage: LocalStorage → IndexedDB
- AI: OpenAI-compatible API

## Philosophy

Small. Fast. Does one thing well.
No accounts. No tracking. Your prompts stay local.
